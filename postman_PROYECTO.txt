B. Forzar Cruce de Horarios (Test de Error)

Si revisamos tu base de datos, tenemos este escenario perfecto para forzar un choque:

Presentación ID 4 (Soda Stereo): Empieza el 20 de noviembre a las 18:00 y dura 90 minutos. Es decir, termina a las 19:30.
Presentación ID 2 (Dua Lipa): Empieza el mismo día a las 19:00 y dura 60 minutos.

Como Dua Lipa empieza media hora antes de que termine Soda Stereo, es humanamente imposible estar en ambos escenarios al mismo tiempo. ¡Vamos a ver cómo tu sistema lo bloquea!

Método: POST 

{
  "presentacionId": 4
}

y luego

{
  "presentacionId": 2
}


para verificar con un método GET a http://localhost:9090/itinerarios/me En el JSON de respuesta que te devuelva, deberías ver solo a Soda Stereo (ID 4) y ni un solo rastro de Dua Lipa. Esto confirma que la transacción se abortó exitosamente y la integridad de la base de datos se mantuvo intacta.
